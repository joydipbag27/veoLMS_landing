# VeoLMS Landing Page Brief

Create a modern, premium landing page for **VeoLMS: Vision for Open Education**.

The page should clearly mention that VeoLMS is an **open-source LMS currently under development**. Visitors should be encouraged to follow the project, view it on GitHub, and contribute.

## Main points to highlight

* Open source and community-driven
* Fully customizable themes and branding
* Modular and plugin-friendly architecture
* Complete ownership of courses, users, and data
* Self-hostable with a managed cloud option planned
* Security-first architecture
* High performance and scalable video delivery
* Cost-effective infrastructure
* Flexible integrations for payments, storage, email, analytics, and video
* Built publicly with documented architecture decisions

## Suggested page sections

1. Hero section introducing VeoLMS
2. GitHub and Join Community buttons
3. Main benefits and feature cards
4. Planned LMS capabilities
5. Open-source and contribution section
6. Short development roadmap
7. Social media and community links
8. Final GitHub call-to-action
9. Footer with project and legal links

Clearly show that the project is not production-ready yet.

## Design direction

Use dark mode by default, with optional light mode. Use deep navy or black backgrounds, blue and cyan accents, subtle gradients, glowing lines, clean cards, and smooth animations.

The design should feel technical, ambitious, fast, and premium, not like a generic course-selling website.

Add GitHub, Discord, YouTube, LinkedIn, and Reddit icons with visible labels.

Keep the page fast, responsive, accessible, and visually impressive without excessive animations.
